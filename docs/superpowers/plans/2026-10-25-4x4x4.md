# 4×4×4 Tic Tac Toe Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the 3×3 game in `index.html` with 4×4×4 tic tac toe played on a rotatable 3D cube, with 2-player and vs-computer (easy, medium, hard) modes.

**Architecture:** Everything ships in the single root `index.html`, split into classic `<script id="…">` blocks: `rules`, `controller`, `geometry`, `ai` are pure logic (no DOM) that attach to `globalThis.Qubic`; `view` holds canvas drawing, DOM, the mode sheet and storage. Node's built-in test runner loads the pure blocks straight out of `index.html` with `node:vm`, so there is no build step and no dependency. Browser behaviour is checked by a smoke test that runs `index.html` plus an injected scenario in headless Chrome.

**Tech Stack:** Plain HTML/CSS/JS, 2D canvas. Node 22 (`node:test`, `node:vm`) for tests. Headless Google Chrome for smoke tests. No npm packages.

**Spec:** `docs/superpowers/specs/2026-10-25-4x4x4-design.md`. Look and interaction reference: `docs/superpowers/specs/2026-10-25-4x4x4-prototype.html` (its "Demo position" button and explanatory text must not ship).

## Global Constraints

- Single `index.html`; no frameworks, libraries, CDN assets, network requests or build step. Must work from `file://` (Android WebView loads `file:///android_asset/index.html`) and offline.
- Touch-first; also works with a mouse. Dark theme, `#111` page background.
- Fits a 360×640 CSS px portrait viewport without scrolling.
- Board indexing: `i = l*16 + r*4 + c`, `l` = layer 0..3 where layer 0 is shown as "Layer 1" and is the top layer.
- X: `rgb(60,150,255)`, O: `rgb(255,70,70)`, placed pieces about 85% opaque.
- Even lattice (spacing 1 in all axes), small-cube half-size `0.32`, tilt clamp `±1.3` rad, tap slop `8` px, initial yaw `-0.6`, pitch `0.45`.
- Against the computer the human is always X and moves first; the computer is O.
- Computer move: about 500 ms pause, search deadline 150 ms, board ignores cell taps meanwhile, rotation still works.
- Exact strings. 2 players: `X's turn · layer 2`, `X: tap again to place`, `X wins`, `O wins`, `Draw`. vs computer: `Your turn · layer 2`, `You: tap again to place`, `Computer is thinking…`, `You win`, `Computer wins`, `Draw`. Mode label: `2 players`, `vs Computer · Easy`, `vs Computer · Medium`, `vs Computer · Hard`. Title: `Tic Tac Toe 4×4×4`.
- Saved mode: `localStorage` key `qubic.mode`, values `pvp|easy|medium|hard`, every access in try/catch.
- Project docs follow the org style: no em dashes.

## Review Focus

- Choosing a new game while the computer is still "thinking": the pending computer move must be dropped, never applied to the new board. (Task 2 test `stale computer move is ignored`; Task 7 smoke step.)
- Missing, blocked or garbage `qubic.mode` in storage: behave like a first launch, never crash. (Task 2 test `parseSavedMode`.)
- The 64th move completes a line: show the win, not "Draw". (Task 2 test `win on the last empty cell beats draw`.)
- A slow phone: the hard level must stop at its deadline instead of freezing the page. (Task 6 test `hard respects the deadline`.)
- Rotating the phone or resizing the window mid-game: the canvas re-lays out and the board, active layer and selection survive. (Task 4 smoke step `resize keeps state`.)

// tests/rules.test.mjs
import { test } from 'node:test';
import assert from 'node:assert/strict';
import { loadQubic, boardOf } from './load.mjs';
const Q = loadQubic('rules');
const lrc = i => [Math.floor(i / 16), Math.floor(i / 4) % 4, i % 4];

test('idx maps layer, row, column', () => {
  assert.equal(Q.idx(0, 0, 0), 0);
  assert.equal(Q.idx(1, 2, 3), 27);
  assert.equal(Q.idx(3, 3, 3), 63);
});

test('76 lines of 4 distinct cells', () => {
  assert.equal(Q.LINES.length, 76);
  for (const L of Q.LINES) assert.equal(new Set(L).size, 4);
  assert.equal(new Set(Q.LINES.map(L => [...L].sort((a, b) => a - b).join())).size, 76);
});

test('48 straight lines, 24 plane diagonals, 4 space diagonals', () => {
  const kinds = { 1: 0, 2: 0, 3: 0 };
  for (const [a, b] of Q.LINES) {
    const A = lrc(a), B = lrc(b);
    kinds[A.filter((v, k) => v !== B[k]).length]++;
  }
  assert.deepEqual(kinds, { 1: 48, 2: 24, 3: 4 });
});

test('16 cells lie on 7 lines, the other 48 on 4', () => {
  const n = Q.LINES_AT.map(a => a.length);
  assert.equal(n.filter(x => x === 7).length, 16);
  assert.equal(n.filter(x => x === 4).length, 48);
  assert.equal(Q.LINES_AT[0].length, 7);
});

test('winningLine finds the space diagonal through 63', () => {
  const b = boardOf([0, 21, 42, 63], []);
  assert.deepEqual([...Q.winningLine(b, 63)].sort((a, b) => a - b), [0, 21, 42, 63]);
  assert.equal(Q.winningLine(b, 1), null);
});

test('three in a row is not a win', () => {
  assert.equal(Q.winningLine(boardOf([0, 1, 2], []), 2), null);
});

test('isFull and other', () => {
  assert.equal(Q.isFull(Array(64).fill('X')), true);
  assert.equal(Q.isFull(boardOf([0], [])), false);
  assert.equal(Q.other('X'), 'O');
  assert.equal(Q.other('O'), 'X');
});
```

### Task 2: Game controller (turns, two-tap placing, modes, status text)

**Files:**
- Create: `tests/controller.test.mjs`
- Modify: `index.html` (add `<script id="controller">` after `rules`)

**Interfaces:**
- Consumes: `Qubic.winningLine`, `Qubic.isFull`, `Qubic.other`.
- Produces (`Qubic`, block `controller`):
  - `MODES = ['pvp', 'easy', 'medium', 'hard']`
  - `createGame(mode) -> State` where `State = { mode, board: string[64], turn: 'X'|'O', activeLayer: 0..3, pending: number (-1 none), last: number (-1 none), winLine: number[]|null, over: boolean, thinking: boolean, gen: number }`, starting `turn 'X'`, `activeLayer 0`, `gen 0`.
  - `restart(s, mode) -> void` resets every field as `createGame` does but keeps the object and sets `gen = s.gen + 1`.
  - `selectLayer(s, l) -> void` sets `activeLayer`, clears `pending`. Allowed while thinking or over.
  - `clearSelection(s) -> void`.
  - `tapCell(s, i) -> 'selected'|'placed'|'ignored'`. Ignored when `over`, `thinking`, cell filled, or `i` not on `activeLayer`. First tap selects, a tap on the pending cell places. Placing sets `last`, clears `pending`, sets `winLine`/`over` (win checked before full board), otherwise switches `turn`; if the mode is not `pvp` and it is now O's turn, sets `thinking = true`.
  - `applyComputerMove(s, i, gen) -> boolean` places O at `i` only if `s.thinking` and `gen === s.gen` and the cell is empty; clears `thinking`; same win/draw/turn logic as a human placement.
  - `statusText(s) -> string`, `modeLabel(mode) -> string`, `parseSavedMode(value) -> mode|null` (exact strings in Global Constraints).

// tests/controller.test.mjs
import { test } from 'node:test';
import assert from 'node:assert/strict';
import { loadQubic } from './load.mjs';
const Q = loadQubic('rules', 'controller');

test('new game defaults', () => {
  const s = Q.createGame('pvp');
  assert.equal(s.turn, 'X'); assert.equal(s.activeLayer, 0); assert.equal(s.pending, -1);
  assert.equal(s.last, -1); assert.equal(s.over, false); assert.equal(s.thinking, false);
  assert.equal(s.board.length, 64); assert.ok(s.board.every(v => v === ''));
});

test('first tap selects, second tap places', () => {
  const s = Q.createGame('pvp');
  assert.equal(Q.tapCell(s, 5), 'selected'); assert.equal(s.pending, 5); assert.equal(s.board[5], '');
  assert.equal(Q.tapCell(s, 5), 'placed');
  assert.equal(s.board[5], 'X'); assert.equal(s.turn, 'O'); assert.equal(s.last, 5); assert.equal(s.pending, -1);
});

test('tapping another cell moves the selection; other layers and filled cells are ignored', () => {
  const s = Q.createGame('pvp');
  Q.tapCell(s, 5); Q.tapCell(s, 6); assert.equal(s.pending, 6);
  assert.equal(Q.tapCell(s, 20), 'ignored'); assert.equal(s.pending, 6);
  Q.tapCell(s, 6); Q.tapCell(s, 7); Q.tapCell(s, 7);
  assert.equal(Q.tapCell(s, 6), 'ignored');
});

test('selectLayer and clearSelection clear the pending cell', () => {
  const s = Q.createGame('pvp');
  Q.tapCell(s, 5); Q.selectLayer(s, 2);
  assert.equal(s.activeLayer, 2); assert.equal(s.pending, -1);
  Q.tapCell(s, 40); Q.clearSelection(s); assert.equal(s.pending, -1);
});

test('2-player status text', () => {
  const s = Q.createGame('pvp');
  assert.equal(Q.statusText(s), "X's turn · layer 1");
  Q.selectLayer(s, 1); Q.tapCell(s, 16);
  assert.equal(Q.statusText(s), 'X: tap again to place');
  Q.tapCell(s, 16);
  assert.equal(Q.statusText(s), "O's turn · layer 2");
});

test('win on the last empty cell beats draw', () => {
  const s = Q.createGame('pvp');
  s.board = Array(64).fill('X'); s.board[0] = s.board[1] = s.board[2] = 'O'; s.board[3] = '';
  s.turn = 'O';
  Q.tapCell(s, 3); Q.tapCell(s, 3);
  assert.equal(s.over, true);
  assert.deepEqual([...s.winLine].sort((a, b) => a - b), [0, 1, 2, 3]);
  assert.equal(Q.statusText(s), 'O wins');
});

test('full board with no line is a draw', () => {
  const s = Q.createGame('pvp');
  s.board = Array(64).fill('X'); s.board[3] = ''; s.turn = 'O';
  Q.tapCell(s, 3); Q.tapCell(s, 3);
  assert.equal(s.over, true); assert.equal(s.winLine, null); assert.equal(Q.statusText(s), 'Draw');
});

test('vs computer: thinking, cell taps ignored, computer move applied', () => {
  const s = Q.createGame('medium');
  assert.equal(Q.statusText(s), 'Your turn · layer 1');
  Q.tapCell(s, 0);
  assert.equal(Q.statusText(s), 'You: tap again to place');
  Q.tapCell(s, 0);
  assert.equal(s.thinking, true); assert.equal(Q.statusText(s), 'Computer is thinking…');
  assert.equal(Q.tapCell(s, 1), 'ignored');
  assert.equal(Q.applyComputerMove(s, 20, s.gen), true);
  assert.equal(s.board[20], 'O'); assert.equal(s.thinking, false); assert.equal(s.turn, 'X');
  assert.equal(Q.statusText(s), 'Your turn · layer 1');
});

test('vs computer end texts', () => {
  const s = Q.createGame('easy');
  s.board[0] = s.board[1] = s.board[2] = 'X';
  Q.tapCell(s, 3); Q.tapCell(s, 3);
  assert.equal(Q.statusText(s), 'You win'); assert.equal(s.thinking, false);
  const t = Q.createGame('easy');
  t.board[16] = t.board[17] = t.board[18] = 'O';
  Q.tapCell(t, 0); Q.tapCell(t, 0);
  Q.applyComputerMove(t, 19, t.gen);
  assert.equal(Q.statusText(t), 'Computer wins');
});

test('stale computer move is ignored', () => {
  const s = Q.createGame('hard');
  Q.tapCell(s, 0); Q.tapCell(s, 0);
  const g = s.gen;
  Q.restart(s, 'easy');
  assert.equal(s.gen, g + 1); assert.equal(s.mode, 'easy'); assert.equal(s.thinking, false);
  assert.equal(Q.applyComputerMove(s, 20, g), false);
  assert.ok(s.board.every(v => v === ''));
});

test('modeLabel and parseSavedMode', () => {
  assert.equal(Q.modeLabel('pvp'), '2 players');
  assert.equal(Q.modeLabel('easy'), 'vs Computer · Easy');
  assert.equal(Q.modeLabel('medium'), 'vs Computer · Medium');
  assert.equal(Q.modeLabel('hard'), 'vs Computer · Hard');
  for (const m of ['pvp', 'easy', 'medium', 'hard']) assert.equal(Q.parseSavedMode(m), m);
  for (const v of [null, undefined, '', 'foo', 'HARD']) assert.equal(Q.parseSavedMode(v), null);
});
```

### Task 3: Cube geometry (projection, hit testing, badge layout)

**Files:**
- Create: `tests/geometry.test.mjs`
- Modify: `index.html` (add `<script id="geometry">`)

**Interfaces:**
- Produces (`Qubic`, block `geometry`):
  - Constants: `HALF = 0.32`, `BADGE_R = 14`, `PERSPECTIVE = 10`, `PITCH_LIMIT = 1.3`, `TAP_SLOP = 8`.
  - `cellCenter(i) -> [x, y, z]` with `x = c - 1.5`, `y = 1.5 - l`, `z = r - 1.5`.
  - `makeCamera({ w, h, yaw, pitch }) -> Camera` with `cx = w/2 + BADGE_R`, `cy = h/2`, and `scale = 1.2 * min(w - 2*(BADGE_R + 14), h) / 2 / hypot(1.5+HALF, 1.5+HALF, 1.5+HALF)` (prototype values).
  - `rotate(cam, [x,y,z]) -> [x,y,z]` (yaw about the vertical axis, then pitch, as in the prototype).
  - `project(cam, [x,y,z]) -> { X, Y, z, s }` where `s = cam.scale * PERSPECTIVE / (PERSPECTIVE + z)`; smaller `z` is nearer.
  - `clampPitch(p) -> number`.
  - `pickCell(hits, x, y) -> number`: `hits` is `[{ i, X, Y, r }]`; returns the `i` with the nearest centre among those within `r`, else `-1`.
  - `spreadBadges(ys, gap, top, bottom) -> number[]`: same order as input; any two badges at least `gap` apart; pushed up if the lowest exceeds `bottom`; none above `top`.

// tests/geometry.test.mjs
import { test } from 'node:test';
import assert from 'node:assert/strict';
import { loadQubic } from './load.mjs';
const Q = loadQubic('geometry');

test('cell centres', () => {
  assert.deepEqual(Q.cellCenter(0), [-1.5, 1.5, -1.5]);
  assert.deepEqual(Q.cellCenter(63), [1.5, -1.5, 1.5]);
});

test('no rotation is identity and the origin projects to the camera centre', () => {
  const cam = Q.makeCamera({ w: 316, h: 470, yaw: 0, pitch: 0 });
  assert.deepEqual(Q.rotate(cam, [1, 2, 3]).map(v => +v.toFixed(9)), [1, 2, 3]);
  const p = Q.project(cam, [0, 0, 0]);
  assert.equal(p.X, cam.cx); assert.equal(p.Y, cam.cy); assert.equal(cam.cx, 316 / 2 + Q.BADGE_R);
});

test('nearer points project larger', () => {
  const cam = Q.makeCamera({ w: 316, h: 470, yaw: 0, pitch: 0 });
  assert.ok(Q.project(cam, [0, 0, -1]).s > Q.project(cam, [0, 0, 1]).s);
});

test('pitch is clamped', () => {
  assert.equal(Q.clampPitch(2), 1.3); assert.equal(Q.clampPitch(-2), -1.3); assert.equal(Q.clampPitch(0.4), 0.4);
});

test('pickCell picks the nearest centre within radius', () => {
  const hits = [{ i: 1, X: 10, Y: 10, r: 8 }, { i: 2, X: 20, Y: 10, r: 8 }];
  assert.equal(Q.pickCell(hits, 14, 10), 1);
  assert.equal(Q.pickCell(hits, 16, 10), 2);
  assert.equal(Q.pickCell(hits, 100, 100), -1);
  assert.equal(Q.pickCell([], 0, 0), -1);
});

test('spreadBadges keeps order, spacing and bounds', () => {
  const ys = Q.spreadBadges([100, 105, 300, 302], 34, 20, 380);
  for (let k = 1; k < 4; k++) assert.ok(ys[k] - ys[k - 1] >= 34);
  assert.ok(ys[0] >= 20 && ys[3] <= 380);
  const low = Q.spreadBadges([370, 372, 374, 376], 34, 20, 380);
  assert.ok(low[3] <= 380 && low[0] >= 20);
});

**Interfaces:**

- Produces:
  - DOM: `h1` "Tic Tac Toe 4×4×4", `#mode` (mode label, dim, small), `#status`, `canvas#cube`, `#hint` ("Drag to rotate · tap a number to pick a layer · tap a cube, then tap again to place"), `button#new` ("New game").
  - `window.qubicTest = { state, tapAt(x, y), screenOf(i) -> {X, Y}, badgeOf(l) -> {X, Y} }` (coordinates in canvas CSS px). A test hook only; no visible effect.
  - `tests/browser.mjs`: `runScenario(js: string) -> Promise<object>` copies `index.html` into a temp dir, injects `<script>` with the scenario before `</body>`, runs Chrome (`process.env.CHROME` or `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`) with `--headless=new --disable-gpu --virtual-time-budget=6000 --dump-dom file://…`, and parses the JSON the scenario writes as `document.title = 'RESULT:' + JSON.stringify(out)`. View behaviour (from the spec and prototype): canvas sized to fill the space between the status line and the hint (full width up to 480 px, height whatever remains, minimum 300 px), redrawn and re-laid-out on `resize`; `devicePixelRatio` aware; `touch-action: none` on the canvas. Pointer down/move/up: movement under `TAP_SLOP` is a tap, otherwise rotation (`yaw += dx * 0.01`, `pitch = clampPitch(pitch + dy * 0.01)`). A tap goes first to badges (within `BADGE_R + 6`), then to `pickCell` over the active layer's empty cubes (radius `HALF * 1.6 * projected scale`), else `clearSelection`. Drawing follows the prototype: back-to-front cubes, faint glass for empty cells, brighter outlines on the active layer, solid shaded X/O, dashed see-through selection in the current player's colour, white outline on `last`, green outlines and line on `winLine`, badges placed with `spreadBadges`. Yaw and pitch live in the view, not the game state, so a restart keeps the rotation. In this task "New game" calls `restart(s, s.mode)` directly; Task 7 changes it to open the sheet. Mode is fixed to `pvp` here.

### Task 5: Computer player, easy and medium

**Files:**
- Create: `tests/ai.test.mjs`
- Modify: `index.html` (add `<script id="ai">` after `controller`)

**Interfaces:**
- Consumes: `Qubic.LINES`, `Qubic.LINES_AT`, `Qubic.other`.
- Produces (`Qubic`, block `ai`):
  - `makeRng(seed) -> () => number` (deterministic, e.g. mulberry32).
  - `threatCells(board, p) -> number[]`: empty cells that would complete a line for `p` (a line with 3 of `p` and 1 empty).
  - `chooseMove(board, me, level, opts?) -> number` where `level` is `'easy'|'medium'|'hard'` and `opts = { rng = Math.random, now = () => performance.now(), deadline = now() + 150 }`. Always returns an empty cell. Does not modify `board`.
- Cell score, shared by all levels (my call; tune only if tests demand): for each line through the cell, if it holds no opponent piece add `[1, 3, 12][own count]`; if it holds no own piece add `[0, 2, 9][opponent count]`; lines holding both add nothing.
- Easy: win if possible, else block an opponent threat, else pick at random (via `rng`) among the 5 best-scoring cells.
- Medium: win, block, else play a cell that gives `me` two or more threats at once (a fork), else block the opponent's fork cell (the best-scoring one if several), else the best-scoring cell with `rng` breaking ties.

### Task 6: Computer player, hard

**Files:**
- Modify: `tests/ai.test.mjs`, `index.html` (`ai` block)

**Interfaces:**
- Consumes/produces: `chooseMove(board, me, 'hard', opts)` from Task 5; same contract.

Hard, in order, checking `opts.now() < opts.deadline` throughout the searches and falling back to the medium answer when time runs out:
1. Win, then block (as medium).
2. Own fork (as medium).
3. Own forced chain: search sequences where each of `me`'s moves creates a threat, the opponent's reply is the forced block, and the chain ends in a fork or win. If the opponent's forced block itself creates an opponent threat, `me`'s next move must be that block cell (and still create a threat), otherwise the branch fails. Depth limit 8 own moves. Play the first move of a found chain.
4. Defence: if the opponent (as if to move) has a forced chain, choose among empty cells one after which the opponent has none, trying cells in the opponent's chains first, then cells that create a threat for `me`, then by score.
5. Otherwise medium's fork-block and best-score rules.

  assert.equal(pick(boardOf([0, 1, 2], [16, 17]), 'O', 'hard'), 3);

test('hard finds a forced chain and wins against forced blocks', () => {
  const b = boardOf([25, 36, 44, 48, 49], [0, 14, 18, 57, 58]);
  const first = pick(b, 'X', 'hard');
  assert.ok([12, 51].includes(first));
  let won = false;
  for (let move = 0; move < 4 && !won; move++) {
    const x = move === 0 ? first : pick(b, 'X', 'hard');
    b[x] = 'X';
    if (Q.winningLine(b, x)) { won = true; break; }
    const t = Q.threatCells(b, 'X');
    assert.ok(t.length >= 1, 'every chain move must threaten');
    b[t[0]] = 'O';
  }
  assert.ok(won);
});

test('hard defends against a forced chain', () => {
  assert.equal(pick(boardOf([25, 36, 44, 48, 49], [0, 14, 18, 57]), 'O', 'hard'), 12);

test('hard respects the deadline', () => {
  const b = boardOf([0, 5, 21, 42, 27, 33], [63, 60, 12, 48, 30]);
  const t0 = performance.now();
  Q.chooseMove(b, 'O', 'hard', { rng: Q.makeRng(3), deadline: performance.now() + 100 });
  assert.ok(performance.now() - t0 < 200);
});

const playGame = (levelX, levelO, seed) => {
  const b = Array(64).fill(''), rng = Q.makeRng(seed);
  let worst = 0;
  for (let n = 0, p = 'X'; n < 64; n++, p = Q.other(p)) {
    const t0 = performance.now();
    const i = Q.chooseMove(b, p, p === 'X' ? levelX : levelO, { rng });
    worst = Math.max(worst, performance.now() - t0);
    assert.equal(b[i], '');
    b[i] = p;
    if (Q.winningLine(b, i)) return { winner: p, worst };
  }
  return { winner: null, worst };
};

test('hard as O does not lose to easy, and every move is quick', () => {
  let losses = 0;
  for (let seed = 1; seed <= 10; seed++) {
    const r = playGame('easy', 'hard', seed);
    if (r.winner === 'X') losses++;
    assert.ok(r.worst < 250, `move took ${r.worst} ms`);
  }
  assert.ok(losses <= 1, `hard lost ${losses} of 10`);
});

test('every level finishes a self-play game with legal moves', () => {
  for (const level of LEVELS) playGame(level, level, 7);
});
